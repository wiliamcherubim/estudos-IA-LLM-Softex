# Projeto P1 — Análise de Viabilidade de IA

**Autor:** Wiliam Cherubim  
**Curso:** IA LLM — Softex Campinas

## Resumo do Caso

Análise técnica para avaliar onde, como e sob quais condições uma instituição de ensino digital deve (ou não) utilizar modelos de linguagem (LLMs) no atendimento aos estudantes.

## Estrutura da Pasta

- [`MEMORANDO_TECNICO.md`](./MEMORANDO_TECNICO.md): Documento principal contendo a análise das funcionalidades, evolução dos prompts, casos de teste, matriz de riscos e recomendação final.
- [`testes_intermediario.py`](./testes_intermediario.py): Script Python utilizado para executar a bateria de 8 testes automatizados com a API do Gemini.
